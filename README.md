# DEEper — исследование на 5–7 минут и что копать дальше

Личный исследовательский поисковик: по теме он сам планирует запросы, ищет и читает десятки источников и пишет отчёт на русском на 5–7 минут чтения — главное, 3–4 раздела, чего пока не знаем, список источников. Главное начинается после отчёта: «что исследовать дальше» запускается одним касанием, продолжение помнит, что уже прочитано в ветке, а у первого отчёта ветки бывает маршрут из нескольких шагов. Для длинных отчётов есть подробный и глубокий режимы. Отчёт сохраняется в PDF, DOCX и Markdown. Работает в веб-приложении, через Telegram-бота и из командной строки.

Оформление — по брендбуку AVEN (made by aven): тёмная тема «ночь / бумага / бордо / янтарь», шрифты Unbounded, Onest и JetBrains Mono.

Внутри: [GPT Researcher](https://github.com/assafelovic/gpt-researcher) (оркестрация исследования), [SearXNG](https://github.com/searxng/searxng) (бесплатный веб-поиск) или Tavily, научные базы arXiv и OpenAlex, модель DeepSeek.

> Старая версия DEEper (Groq + Tavily) сохранена в ветке [`legacy`](https://github.com/MrBoomer1981/DEEper/tree/legacy).

## Режимы

| Режим | Что делает | Пример |
|---|---|---|
| `quick` — «Обзор», по умолчанию | один проход поиска, отчёт на 5–7 минут чтения: «Главное», 3–4 раздела, «Чего пока не знаем» | ~1,5–3 мин на Pro с проверкой фактов, 800–1 000 слов (5–6 минут), ≈ 2–2,7 ₽ |
| `detailed` — «Подробно» | введение, отдельное исследование под каждую подтему (все сразу), заключение | ~5–7 мин на Pro, ~5 на Flash; до 5 000 слов (обычно 3,5–4,5 тыс., около 20 минут чтения), 35–40 источников в тексте |
| `deep` — «Глубоко» | рекурсивный поиск вширь и вглубь, затем один отчёт | дольше всех |

Источники: `web` (SearXNG или Tavily), `academic` (arXiv, OpenAlex), `all` — по умолчанию.

Обзор — 800–1 000 слов без списка источников (замер на 4 темах: в среднем 2:08 и 2,44 ₽ с проверкой фактов), любой отчёт не длиннее 5 000 слов: подробный делит их между введением, разделами и заключением. Время чтения считается из 180 слов в минуту и видно на отчёте, в «Библиотеке», на карточках продолжений и в боте. Итоговый текст и ответы на вопросы пишет DeepSeek V4 Pro (`--writer pro`, по умолчанию), поиск, планирование и отбор источников — DeepSeek Flash. Для дешёвых черновиков: `--writer flash` или переключатель «Pro / Flash» в приложении. Стоимость каждого отчёта и вопроса считается по реальным токенам и тарифам DeepSeek (с учётом ночной скидки) и показывается в рублях.

Поиск с упором на англоязычные источники: модель формулирует поисковые запросы на английском (для тем про конкретную страну — один на её языке), исходный запрос ищется как есть, а отчёт пишется на русском. На тестовой теме доля англоязычных источников выросла с 26% до 82%.

Отбор источников: до скачивания страниц модель видит заголовок и описание каждого найденного результата и ставит оценку 0–3 за релевантность теме, надёжность и свежесть. Известные домены (`.gov`, `.edu`, научные издательства, IEA, ООН, крупные СМИ) только повышают оценку релевантного источника. Не по теме, магазины, соцсети и мусор отбрасываются, SEO-блоги берутся, только если ничего лучше нет. С одного сайта — не больше 2 ссылок на запрос и 5 на исследование. На тестовой теме: статей не по теме было 18 из 32, стало 0; доменов 11 → 16; доля источников, использованных в тексте, 12% → 36%. Отключить: `SOURCE_FILTER=off`.

## Запуск на своём компьютере

Нужны Docker, [uv](https://docs.astral.sh/uv/) и ключ [DeepSeek](https://platform.deepseek.com/api_keys). На macOS для PDF: `brew install pango`.

```bash
cp .env.example .env          # впишите DEEPSEEK_API_KEY и SEARXNG_SECRET (openssl rand -hex 32)
docker compose up -d          # локальный SearXNG на 127.0.0.1:8080
uv run research.py "тема"     # обзор на 5–7 минут; отчёт появится в reports/
uv run research.py "тема" --mode detailed   # подробный отчёт
uv run research.py "тема" --mode deep --sources all --words 2500
uv run app.py                 # приложение, исследователь и бот (если задан токен) в одном процессе
```

## Из чего состоит

Пять частей, каждую можно улучшать и перезапускать отдельно:

| Часть | Что делает |
|---|---|
| **core** — ядро | веб-приложение, API, библиотека отчётов, очередь исследований, список заблокированных сайтов |
| **worker** — исследователь | само исследование (GPT Researcher и наши доработки), подсказки, ответы на вопросы, сборка PDF и DOCX |
| **search** — поиск | отбор источников и чтение страниц с запасными способами (Europe PMC, OpenAlex, Jina Reader) |
| **news** — новости | собирает новости об ИИ из 86 независимых источников (блоги лабораторий, статьи, СМИ, аналитики, сообщества, русские сайты, Telegram-каналы), склеивает дубли в сюжеты и отдаёт их боту и «Радару». Вторая полоса — возможности с дедлайнами: хакатоны, школы, стажировки, гранты (64 источника: агрегаторы хакатонов, Devpost, школы ML, программы AI safety, каналы компаний и ИТМО, наука и молодые учёные; плюс поиск по вебу раз в неделю). |
| **bot** | Telegram-бот, работает через API ядра |

`uv run app.py` запускает всё в одном процессе — так работает и Railway. По отдельности: `uv run python -m my_browser.core` (и `.worker`, `.search`, `.news`, `.bot`) с адресами друг друга в `CORE_URL`, `WORKER_URL`, `SEARCH_URL`, `NEWS_URL` и общим `SERVICE_TOKEN`. Очередь исследований хранится в базе: если сервер перезапустится посреди исследования, оно станет «прервано» и его можно перезапустить кнопкой в приложении или в боте.

### Работа над одной частью

У папки каждой части (`my_browser/core`, `worker`, `search`, `news`, `bot`, а ещё `common`, `eval` и `proxy`) свой `CLAUDE.md`. В нём написано, что делает часть, как запустить и проверить её отдельно и чего от неё ждут остальные. Отдельную сессию Claude Code можно открыть прямо в папке:

```bash
cd my_browser/search && claude
```

Такая сессия сама подхватывает общие правила проекта и память и видит весь репозиторий. Коммитит она только свои файлы. Перед коммитом сессия запускает `/check-project`, бесплатную проверку всего проекта: все модули импортируются, а одно исследование проходит целиком с тестовой моделью `dev/mock_llm.py` вместо DeepSeek. Несколько сессий могут работать одновременно: у каждой свои порты и своя папка для отчётов.

## Приложение (телефон, Mac, браузер)

Сделано прежде всего для телефона. Внизу четыре раздела: «Поиск», «Радар», «Библиотека», «Фокус». Они переключаются мгновенно, без перезагрузки страницы, а отчёт и ход исследования открываются с плавным переходом. Оформление и маскот Дип-Диггер описаны в `DESIGN_HANDOFF.md`.

- **Поиск.** Тема вводится в поле внизу экрана. Кнопка режима в поле («Обзор») открывает настройки: режим, источники, модель, проверку фактов и «Уточнить тему». Уточнение задаёт 2–3 вопроса с вариантами (регион, цель, аспект), и ответы встраиваются в тему.
- **Ход исследования.** Процент, этап и последние прочитанные источники. Когда отчёт начинает писаться, текст появляется на экране абзацами — его можно читать, не дожидаясь конца. Если к готовности вы уже листаете, отчёт не откроется сам: внизу появится «Отчёт готов — открыть с этого места». Исследование, которое ещё не началось, можно отменить. Экран можно закрыть: отчёт появится в «Библиотеке».
- **Отчёт.** На экране только текст, над ним — время чтения и, если ветка идёт по маршруту, «маршрут · 2 / 5» со списком шагов. Ссылки заменены номерами, оглавление «3 / 9 ▾» следит за прокруткой. В «⋯» лежат PDF, DOCX и MD, источники с блокировкой сайтов и вопросы по отчёту. Там же «Сократить до 1 500 слов»: Pro оставляет выводы, ключевые факты и числа с их ссылками, а краткая версия сохраняется рядом с полной. На отчёте в 7 500 слов это заняло 28 с и стоило 2,15 ₽. Выделенный текст можно сохранить в закладки, задать по нему вопрос или начать по нему новое исследование («Глубже»).
- **«Что исследовать дальше»** в конце отчёта — главное после самого отчёта. Первой идёт следующая остановка маршрута, если он есть, затем четыре темы разных видов: «Глубже», «Против» (самые сильные контраргументы) и две из «На практике», «Для меня» (по профилю из «Фокуса» и `/profile` бота), «Свежее», «Рядом». На каждой — зачем это читать, время чтения и цена. Касание сразу запускает исследование (5 секунд его можно отменить), и новый отчёт становится продолжением текущего: модель знает «Главное» прочитанных отчётов ветки, не пересказывает их и начинает с нового. Маршрут предлагает первый отчёт ветки, если тема широкая: 3–5 следующих шагов, как короткий курс; каждый шаг знает, где он в маршруте, и не залезает в соседние. Рядом показаны продолжения и похожие отчёты из библиотеки. Тот же раздел есть в конце PDF, DOCX и Markdown. Если ответа на вопрос в отчёте нет, приложение предложит тему для отдельного исследования.
- **«Проверка фактов»**: после написания отчёта каждое утверждение со ссылкой сверяется с той страницей, которую читало исследование. Если сказанное есть в другом прочитанном источнике, ссылка меняется на него; если источник даёт другие числа, даты или имена, предложение исправляется по нему. Неподтверждённые места отмечены «?» в тексте и собраны в разделе «Проверка фактов» в конце отчёта (и в PDF, DOCX, Markdown). По умолчанию проверка включена во всех режимах. Переключатель есть в «Подробно» на экране поиска и в «Фокусе».
- **Библиотека**: отчёты со временем чтения (идущие исследования сверху), закладки и поиск по всем отчётам.
- **Фокус**: настройки по умолчанию и пресеты («Учёный», «Аналитик», «Новости»), сайты, которые не брать, граффити.
- **Радар**: главные новости об ИИ за полтора дня. Одна новость из многих источников — один сюжет: сколько независимых источников о нём написали, есть ли среди них первоисточник, заголовок и резюме по-русски. «Копнуть глубже» начинает исследование по сюжету, стрелка открывает источник. Ниже — темы «Что исследовать дальше» из отчётов, которые ещё не исследованы: касание запускает, как под отчётом. Вкладка «Возможности»: открытые хакатоны, соревнования, школы, стажировки и гранты, до срока которых не больше 3 месяцев (у крупных — 6), с фильтром по типу. Новые возможности приходят только сюда. Список обновляется раз в день, в 08:00 по Москве: всё найденное за сутки появляется сразу, сверху — «Новые». Что дальше по сроку, появится, когда срок приблизится. Под новыми — «Ждём»: крупные ежегодные события (Конгресс молодых учёных, Yandex Cup, ШАД, MATS, летние школы ML и другие), регистрация на которые обычно уже открыта, но радар их ещё не нашёл. Раз в неделю радар сам ищет в вебе то, о чём не написали его источники. У каждой — дедлайн, формат, можно ли участвовать из России и почему подходит; стрелка ведёт на подачу, а строка открывает карточку: даты, кто может участвовать, что дают, стоимость и кнопки «В мои», «Регистрация есть», «Исследовать», «Не моё». Вкладка «Мои» — куда регистрация уже есть, а куда ещё нет: кружок слева отмечает регистрацию одним касанием, прошедшие события уходят вниз. Это те же отметки, что 📌 и ✅ в боте: по выбранным приходят напоминания о дедлайне, после регистрации они прекращаются.

```bash
uv run app.py                 # http://127.0.0.1:8501 (порт 8080 занят локальным SearXNG)
```

На Railway приложение работает в том же сервисе, что и бот (общая история отчётов), и закрыто паролем `APP_PASSWORD`.

**Установить без App Store.** На iPhone: Safari → «Поделиться» → «На экран Домой». На Mac: Safari → «Файл» → «Добавить в Dock». Появится отдельное приложение DEEper со своей иконкой (на Mac — в Dock, Launchpad, Spotlight и Cmd+Tab).

## Telegram-бот

Пришлите тему — бот предложит кнопками режим («⚡ Обзор» первым), источники, проверку фактов (и «Уточнить тему»), покажет ход работы и пришлёт PDF, DOCX, Markdown, «Главное» сообщением и «что исследовать дальше»: номер темы сразу запускает обзор-продолжение, ➡️ — следующий шаг маршрута; 5 секунд его можно отменить кнопкой «✖️ Отменить». Ответьте на сообщение с номером отчёта (`#N`), чтобы задать вопрос по нему; если ответа в отчёте нет, бот предложит исследовать вопрос отдельно.

| Команда | |
|---|---|
| `/history` | последние отчёты |
| `/view N` | прислать отчёт N ещё раз |
| `/search текст` | поиск по всем отчётам |
| `/ask N вопрос` | вопрос по отчёту N |
| `/delete N` | удалить отчёт N |
| `/block домен` | не использовать сайт как источник (`/unblock`, `/blocked`) |
| `/news` | новости об ИИ: сколько источников работает, посты за сутки, расход; возможности: сколько в приложении и из них новых, сколько ждут своего срока, сколько отслеживается, каких ежегодных ещё не нашли, ближайший дедлайн, расход |
| `/sources`, `/add`, `/remove` | источники новостей: список и состояние (💤 — источник возможностей молчит дольше обычного), добавить RSS-ленту или @канал, выключить |
| `/time 09:00 18:00`, `/quiet 23:00 08:00`, `/urgent 8` | время дайджестов, тихие часы, порог срочного (у каждой — `off`) |
| `/topics`, `/pause`, `/resume` | темы новостей кнопками; пауза и продолжение |
| `/dropped` | что отсеяно из новостей за сутки и почему; «↩️» возвращает сюжет и учит бота |
| `/profile` | профиль, по которому оцениваются возможности; `/profile текст` — заменить |
| `/opps`, `/deadlines`, `/opptypes` | те же возможности, что в приложении, с фильтром по типам; отслеживаемые по дате; какие типы показывать |
| `/add opps @канал` или ссылка | источник возможностей: канал, лента или страница программы |

**Возможности** бот не присылает: новые — только в приложении, «Радар» → «Возможности», список обновляется каждое утро в 08:00. В бот приходят напоминания о дедлайнах тех, что отслеживаются («В мои» в приложении или 📌 в `/opps`): за 14, 3 и 1 день, и «дедлайн перенесён». ✅ — заявка подана, ✖️ — не буду.

**Новости** приходят сами: срочное — сразу (ночью ждёт утра), дайджест — в 09:00 и 18:00 по Москве, до 15 сюжетов. 🟢 — есть первоисточник, 🟡 — только пересказы. Кнопка 🔎 под сюжетом запускает по нему исследование, 👍/👎 — отзыв: темы и источники с 👍 поднимаются выше, с 👎 — опускаются. Статус — `/news`.

Бот личный: отвечает только пользователям из `TELEGRAM_ALLOWED_USERS`. Остальным он сообщает их Telegram ID — так удобно узнать свой.

## Деплой на Railway

Сборка по `Dockerfile`: в настройках сервиса на Railway выбран сборщик Dockerfile (Settings → Build → Builder), одна реплика. SearXNG на Railway не поднимается, поэтому веб-поиск там идёт через Tavily (бесплатно 1000 запросов в месяц): он включается сам, когда задан `TAVILY_API_KEY`, а `SEARX_URL` — нет. Явно выбрать поиск можно переменной `WEB_RETRIEVER`.

**Из России без VPN.** Адрес Railway (`*.up.railway.app`) из российских сетей не открывается, а Cloudflare открывается. Поэтому перед приложением стоит бесплатный прокси на Cloudflare Workers (`proxy/`): телефон открывает `deeper.<поддомен>.workers.dev`, а прокси передаёт всё приложению на Railway. Выложить его: в папке `proxy/` выполнить `npx wrangler login`, `npx wrangler secret put ORIGIN` (адрес приложения на Railway) и `npx wrangler deploy`. На мобильном интернете прокси не открывается: с июня 2025 года российские провайдеры пропускают к адресам Cloudflare только первые ~16 КБ на соединение. Для этого подготовлен свой сервер в России (`proxy/ru/`), пока он в архиве (`plan.md`, раздел «Архив»).

Переменные сервиса:

| Переменная | Значение |
|---|---|
| `DEEPSEEK_API_KEY` | ключ DeepSeek |
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather (старое имя `TELEGRAM_TOKEN` тоже подходит) |
| `TELEGRAM_ALLOWED_USERS` | ваш Telegram ID (несколько — через запятую) |
| `APP_PASSWORD` | пароль входа в веб-приложение |
| `TAVILY_API_KEY` | ключ [Tavily](https://app.tavily.com) |
| `JINA_API_KEY` | необязательно: бесплатный ключ [Jina Reader](https://jina.ai/reader). Страницы, которые не скачались напрямую, читаются через Jina: с ключом 500 в минуту, без ключа 20 |

Чтобы отчёты и история переживали передеплой, подключите к сервису Volume с путём монтирования `/app/reports`.

## Настройки

Модели, длина отчётов, число подтем и параметры глубокого режима — в `config.json`. Любой ключ оттуда можно переопределить переменной окружения или строкой в `.env`.

## Замеры качества

```bash
uv run eval/run.py                    # 7 постоянных тем из eval/topics.txt, ≈ 10 ₽ за прогон
```
